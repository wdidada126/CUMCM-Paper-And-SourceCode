# 数据文件说明

## 必需的数据文件

请将以下数据文件放在 `define.py` 中定义的 `xlsx_path` 路径下（默认路径：`C:\iCloudDrive\项目\高教杯\数据`）：

### 1. 附件1.xlsx
**用途**: 品类信息数据  
**包含字段**:
- 单品编码
- 单品名称
- 分类名称
- 单品净名称
- 平均损耗率
- 其他相关字段

### 2. 附件2.xlsx
**用途**: 销售数据  
**包含字段**:
- 销售日期
- 单品编码
- 销量(千克)
- 销售单价(元/千克)
- 扫码销售时间
- 其他相关字段

### 3. 附件3.xlsx
**用途**: 批发价格数据  
**包含字段**:
- 日期
- 单品编码
- 批发价格(元/千克)
- 其他相关字段

## 数据文件获取

数据文件应从全国大学生数学建模竞赛官网或竞赛题目附件中获取。

## 文件格式要求

- Excel文件格式: .xlsx
- 编码: UTF-8
- 第一行应为列名
- 不要删除或重命名关键列

## 数据文件检查

运行以下命令检查数据文件是否齐全：

```bash
./run.sh test
```

或者手动检查：

```bash
ls -la 附件1.xlsx 附件2.xlsx 附件3.xlsx
```

## 数据文件示例

如果缺少数据文件，可以创建示例数据进行测试：

```python
import pandas as pd

# 创建示例品类数据
category_data = {
    '单品编码': range(1, 101),
    '单品名称': [f'单品{i}' for i in range(1, 101)],
    '分类名称': ['水生根茎类'] * 20 + ['花叶类'] * 20 + ['花菜类'] * 20 + 
                ['茄类'] * 20 + ['辣椒类'] * 10 + ['食用菌'] * 10,
    '单品净名称': [f'单品净{i}' for i in range(1, 101)],
    '平均损耗率': [0.05 + i*0.01 for i in range(1, 101)]
}

# 创建示例销售数据
sales_data = {
    '销售日期': pd.date_range('2023-01-01', periods=1000, freq='D'),
    '单品编码': [1, 2, 3] * 333 + [4],
    '销量(千克)': [10 + i*0.5 for i in range(1, 1001)],
    '销售单价(元/千克)': [5 + i*0.1 for i in range(1, 1001)]
}

# 创建示例批发价格数据
cost_data = {
    '日期': pd.date_range('2023-01-01', periods=1000, freq='D'),
    '单品编码': [1, 2, 3] * 333 + [4],
    '批发价格(元/千克)': [3 + i*0.05 for i in range(1, 1001)]
}

# 保存为Excel文件
pd.DataFrame(category_data).to_excel('附件1.xlsx', index=False)
pd.DataFrame(sales_data).to_excel('附件2.xlsx', index=False)
pd.DataFrame(cost_data).to_excel('附件3.xlsx', index=False)
```

## 常见问题

### Q: 数据文件路径错误？
A: 修改 `define.py` 文件中的 `xlsx_path` 变量为实际的数据文件路径。

### Q: 数据文件格式不支持？
A: 确保使用Excel格式（.xlsx），不要使用.csv或其他格式。

### Q: 数据文件列名不匹配？
A: 检查数据文件的列名是否与代码中要求的列名一致，必要时修改数据文件或代码。

### Q: 如何修改数据文件路径？
A: 在 `define.py` 文件中修改以下变量：
```python
xlsx_path = r'你的数据文件路径'
fig_path = r'你的图片保存路径'
model_path = r'你的模型保存路径'
```
